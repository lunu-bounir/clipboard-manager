Helper Component

  • Browser + System Mode: polls the clipboard of all applications while the browser is running.
  • Browser + System Events Mode: captures clipboards from all applications using the browser's change events; no polling is performed. Available on ChromeOS only.
  • Content Script Mode: collects clipboards of this browser's pages only.
  • Native Client Mode: collects all clipboards system-wide; needs the optional helper installation.

With "Browser + System" mode, clipboards from all applications are collected as long as the browser is running. No installation is needed. The polling interval can be changed in the options page. Pressing Save will ask for your permission to read the clipboard text.
With "Browser + System Events" mode, clipboards from all applications are collected as soon as they change; nothing is polled in the background. This mode is available on ChromeOS only. Pressing Save will ask for your permission to read the clipboard text.
With "Content Script" mode, only clipboards made within HTML pages of this browser are collected. Pressing Save will ask for your permission to read the clipboard text and run on all websites.

For system-wide clipboard collection, the open-source native component is needed. To install it:

  1. Download and extract the installer script
  2. Run install.sh in a terminal
  3. Double-click install.bat
  4. Press the "Test" button

The component is removed any time with uninstall.sh.
